# 🌍 Air Quality Data Analysis & Prediction

An end-to-end data analytics and forecasting project built using Python and Power BI to analyze hourly air-quality and environmental data.

The project analyzes 9,357 observations containing pollutant sensor readings, temperature, relative humidity, absolute humidity, and forecast values.

## 🎯 Objective

The objective of this project is to:

- Analyze air-quality and environmental patterns
- Identify relationships between environmental variables
- Compare actual and forecasted Relative Humidity (RH)
- Analyze forecast uncertainty
- Build an interactive Power BI dashboard
- Convert complex sensor data into actionable insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Power BI
- DAX
- CSV

## 📊 Dashboard

The Power BI dashboard provides:

- Forecast Line Chart
- Forecast vs Actual Comparison
- Uncertainty Band Area Chart
- KPI Cards
- Environmental trend analysis

## 📈 Key Insights

- Dataset contains 9,357 hourly observations.
- Data covers March 2004 to April 2005.
- Forecasted values have an average of approximately 49.23.
- Forecast values range from approximately 20.17 to 74.78.
- Prediction intervals range from approximately 4.07 to 90.94.
- Actual RH and forecast values show a meaningful relationship.
- Several sensor variables contain `-200` as a missing-value indicator, making data preprocessing an important part of the analysis.

## 💡 Business/Analytical Value

The dashboard provides an intuitive way to monitor environmental trends, compare predictions against observations, and understand the uncertainty associated with forecasts.
